## Behavior changes visible in-game

- **Cross-session memory**: every player command, plan completion, plan failure, and correction is logged as an `AgentEvent`. Before each LLM call, top-3 most-relevant memories are injected as `<memories>` framework messages.
- **Corrections persist**: `agent: don't put torches on dirt` → LLM calls `rememberCorrection(...)` with importance=9. Next session, the correction is retrieved and influences plans.
- **Reflections**: on Plan completion/failure, a 2-3 sentence reflection is generated by `ReflectionService` and stored as `type=reflection`, importance=7 (success) or 8 (failure). Future plans retrieve and reference them.
- **Shadow JAR safety**: `./gradlew build` now fails if any forbidden third-party packages slip through unshaded — catches relocation misses at CI time instead of at runtime.

## Decisions made

- **Importance scoring** for episodic events: LLM-scored 1-10 at write time, with a fallback default of 5 on parse error. Bypassed via `writeWithImportance(...)` for known-importance writes (corrections=9, reflections=7-8).
- **Recency decay**: `exp(-ageHours / 8)` — events 8 hours old contribute ~37% of full recency.
- **Retrieval** is a session-scoped query (per-server). Three-factor sum without weights — Generative Agents default.
- **Reflection skipped on CANCELLED** — interrupted plans don't get postmortems.
- **`com.sun` relocation removed**: it was rewriting JDK internals (`com.sun.management`, etc.), which is dangerous and was a known MINOR-6 finding.
